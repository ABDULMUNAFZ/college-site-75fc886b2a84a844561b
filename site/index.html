GitHub Actions → Azure Blob Storage

The college lab timings site that publishes itself.

A staff member edits one file in GitHub. A workflow uploads the site to Azure Blob Storage and stamps the commit it deployed. Nobody opens the Azure portal. Nobody uploads anything by hand.

  • Lab slots read straight from data.json
  • Every commit stamped with its real SHA and run
  • Static files only — no server, no database
